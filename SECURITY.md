# Security policy

This repository is an experimental read-only admission boundary. Do not use it
to authorize shell commands, writes, network calls, publication, financial
operations, or other external actions.

Please report suspected boundary bypasses privately to the repository owner
before opening a public issue. Do not include secrets, model weights, customer
data, or private repository contents in a report.

The CRC32 fields are integrity checks for fixed binary frames, not signatures,
MACs, or proof of source authority.
